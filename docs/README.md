# Prévia web do Bibliotech

Esta pasta publica apenas a interface do aplicativo Electron no GitHub Pages. É possível navegar pelas telas, alternar o tema e consultar os documentos de ajuda. A prévia não se conecta ao banco de dados e não salva cadastros, empréstimos ou relatórios.

O código original do aplicativo está em [aalmmaa-group/Bibliotech](https://github.com/aalmmaa-group/Bibliotech).
